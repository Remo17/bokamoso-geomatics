# Bokamoso Geomatics — Stitch Design Brief

## Project

Bokamoso Geomatics is an existing company website.

The existing website is the source of truth for the brand identity, visual language, typography, colors, spacing, navigation, buttons, cards, imagery, layout conventions, and overall aesthetic.

The goal is NOT to redesign Bokamoso.

The goal is to design the currently incomplete/missing pages so they look like they were originally created as part of the same website.

## Critical instruction

Study the attached Bokamoso website carefully before designing anything.

Extend the existing design system rather than introducing a new one.

Do NOT:
- redesign the homepage
- change the existing brand identity
- introduce a generic AI-generated corporate aesthetic
- introduce unrelated colors
- introduce a different typography system
- create a completely different navigation style
- replace the existing visual language
- make the pages look like templates from another website

The new pages must feel native to the existing Bokamoso website.

## Missing / incomplete pages

Design the following pages:

1. Services
2. Projects
3. Expertise
4. Contact
5. Request a Quote

## Services

Create a comprehensive services page for a geomatics company.

The page should clearly communicate Bokamoso's professional geomatics capabilities.

Use the existing site's visual language for:
- service cards
- section layouts
- typography
- buttons
- imagery
- spacing
- calls to action

Services should be presented in a clear hierarchy rather than as an excessive wall of text.

Include an appropriate CTA leading users toward contacting Bokamoso or requesting a quote.

## Projects

Create a professional project portfolio page.

The page should allow visitors to understand Bokamoso's previous/project capabilities through visually strong project presentation.

Use:
- project imagery
- project titles
- concise descriptions
- relevant categories or disciplines where appropriate

The layout should remain consistent with the existing website.

Include a clear route toward contacting Bokamoso or requesting a quote.

## Expertise

Create a page explaining Bokamoso's technical and professional expertise.

The page should communicate the company's capabilities in a structured way.

Use visual hierarchy and concise content rather than large blocks of text.

Possible areas can include:
- surveying
- GIS
- mapping
- geospatial data
- land surveying
- spatial analysis
- related geomatics disciplines

Only include areas that fit naturally with Bokamoso's existing company positioning.

## Contact

Create a polished contact page consistent with the existing website.

Include:
- contact information
- company location information where appropriate
- email/contact method
- phone/contact method where available from the existing website
- contact form
- clear CTA

The page should make contacting Bokamoso straightforward.

## Request a Quote

Create a dedicated quote-request experience.

The page should contain a professional form appropriate for a geomatics company.

Potential fields include:
- name
- company
- email
- phone
- project type
- project location
- project description
- additional requirements

Keep the form practical and not unnecessarily long.

The page should clearly communicate what happens after submitting a request.

## Responsive design

Every page must be designed for:

- desktop
- tablet
- mobile

Responsive behavior must feel intentional.

Do not simply stack desktop elements vertically.

Preserve the existing Bokamoso spacing, typography, hierarchy, navigation behavior, and visual character across screen sizes.

## Visual quality

The final designs should feel like a real professional geomatics company website.

Prioritize:
- strong hierarchy
- clean composition
- restrained use of visual effects
- professional imagery
- excellent spacing
- clear calls to action
- consistency with the existing Bokamoso website

Avoid:
- excessive gradients
- excessive glassmorphism
- random floating cards
- unnecessary animations
- generic SaaS layouts
- generic AI landing-page aesthetics

## Final requirement

The five pages should look as though they were designed by the same designer who created the existing Bokamoso website.

The existing website is the visual source of truth.
